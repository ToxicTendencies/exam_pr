# ExamTraining — HANDOFF

Проект использует многопредметную архитектуру и поддерживает обычные тестовые задания и билеты с развёрнутым ответом.

## Данные

Источник истины:

```text
data/subjects/*.json
```

Каждый не начинающийся с `_` JSON — отдельный предмет.

Сборка данных:

```bash
python tools/build_data_bundles.py
```

Генерируются:

```text
app/src/main/assets/subjects_core.js
app/src/main/assets/subject_data/<subject_id>_explanations.js
```

Не редактировать эти runtime-файлы вручную.

## UI

На основных экранах заголовком является название текущего предмета. Нажатие открывает модальное окно выбора предмета.

Прогресс, очередь ошибок, последний вопрос и настройка немедленной проверки теста хранятся отдельно для каждого `subject.id`.

Тема и пользовательские цвета общие для приложения.

## Хранение состояния

Ключи приложения используют префикс `examtraining_`. Прогресс хранится отдельно для каждого `subject.id`.

## Формат

См. `docs/SUBJECTS_DATA_FORMAT.md` и `data/subjects/_subject_template.json`.


## Билеты

Поддерживается тип `ticket`. В исходном JSON он хранится как:

```json
{
  "id": 1,
  "type": "ticket",
  "ticket": "Формулировка билета",
  "answer_markdown": "Развёрнутый ответ"
}
```

В режиме обучения билет раскрывается кнопкой «Показать ответ», затем пользователь вручную отмечает «Знаю» или «Повторить». Билеты не входят в автоматически оцениваемый тест.


## Безопасный выбор цвета

Настройка пользовательских цветов не использует HTML `input type="color"`. Нажатие на цветной образец открывает встроенный редактор RGB + HEX внутри WebView. Это исключает зависимость от системного Android color chooser и предотвращает падение на несовместимых версиях WebView.
