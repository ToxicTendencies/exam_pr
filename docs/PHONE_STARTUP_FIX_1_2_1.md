# Phone startup hardening — 1.2.1

Версия 1.2.1 делает нативный запуск Android-оболочки диагностируемым и устойчивее к проблемам системного WebView.

Изменения:

- `MainActivity` перехватывает ошибку инициализации WebView вместо немедленного завершения приложения;
- на Android 8.0+ обрабатывается `WebViewClient.onRenderProcessGone`, поэтому падение/завершение renderer-процесса не должно автоматически закрывать всё приложение;
- при проблеме показывается экран с версией Android, WebView и текстом исключения;
- сетевые загрузки по-прежнему запрещены;
- разрешены только локальные URL из `file:///android_asset/`;
- удалены лишние deprecated-настройки доступа `file://`, которые приложению не требуются;
- очистка WebView при закрытии также защищена от исключений;
- versionCode: `13`;
- versionName: `1.2.1`.

Если приложение после этой версии показывает диагностический экран, сделайте его скриншот. Текст ошибки даст точную причину сбоя на конкретном телефоне.
