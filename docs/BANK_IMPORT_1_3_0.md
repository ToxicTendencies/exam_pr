# ExamTraining 1.3.0 — импорт банков билетов и тестов

- Добавлены манифесты `2.2-subject-import` и подключение нескольких исходных JSON-файлов к одному предмету.
- Добавлено преобразование `open_text` с вложенным полным ответом в билет.
- Добавлено стабильное смещение ID импортируемых банков.
- Сохранены метаданные `ticket_number`, `ticket_question_number`, `topic`, `subtopic`, `difficulty`, `skill`.
- В банке расширен поиск по теме, подтеме и вариантам.
- В тесте добавлен фильтр по билету.
- Подключён предмет «Биология»: 59 билетов и 1281 тестовый вопрос.
- Тестовые фикстуры больше не попадают в релизный список предметов.
