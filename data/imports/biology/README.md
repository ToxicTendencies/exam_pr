# Исходные банки биологии

- `biology_tickets.json` — 59 экзаменационных вопросов с развёрнутыми ответами. Исходный тип `open_text` автоматически преобразуется сборщиком в `ticket`, потому что `accepted_answers` пуст, а полный ответ находится в объекте `answer`.
- `biology_tests.json` — 1281 тестовый вопрос типов `single_choice` и `multiple_choice` с разборами.

Предмет подключается через `data/subjects/biology.json`. Тестовым вопросам назначается смещение ID `10000`, чтобы их идентификаторы не пересекались с билетами.
